# AGENTS.md (Project Instructions)

## Quick Reference

- **Project**: `ai-labels-font` — TTF font of 3 EU AI Act label icons (AI, AI Modified, AI Generated)
- **Dependencies**: Python 3.12+, `fonttools`, `cu2qu`
- **Build**: `python3 build-font.py`

## File Structure

```
au-ai-iconfont/
├── AGENTS.md          ← this file
├── README.md          ← user docs (installation, usage, license)
├── fonts/
│   ├── ai-labels-font.ttf        ← built TTF font
│   ├── ai-labels-font.html       ← interactive demo page
│   ├── ai-labels-font.css        ← CSS utility classes
│   └── build-font.py             ← build script (SVG → TTF)
└── icons/              ← SVG source files (EU AI Act icons)
    ├── LABEL_AIblack.svg              ← source for U+E001 (type: "ai")
    ├── LABEL_AI GENERATED_black.svg ← source for U+E003 (type: aig")
```

## Build Glyphs

The build script reads SVG files from `icons/` and produces font files with the following glyph map.

Glyph Map:

| Glyph Name       | PUA Codepoint | Ligature (type this) | Source SVG File                      |
|-----------------|---------------|----------------------|-------------------------------------|
| ai.general       | U+E001        | ai, AI, Ai, AiM      | `icons/LABEL_AI_black.svg`          |
| ai.modified      | U+E002        | aim, AIM, Aim        | `icons/LABEL_AI MODIFIED_black.svg` |
| ai.generated     | U+E003        | aig, AIG, Aig        | `icons/LABEL_AI GENERATED_black.svg`|

All other icons in `fonts/` — `html`, `css`, and `build-font.py` — are auto-generated by `python3 fonts/build-font.py`.

### Build Script

```bash
cd fonts/
pip3 install fonttools cu2qu
python3 build-font.py
```

Output: `fonts/ai-labels-font.ttf` (plus HTML demo, CSS, and WOFF2/EOT if binary available).

### Add New Glyphs

Edit `GLYPH_DEFS` in `fonts/build-font.py` to add new SVG files:

```python
GLYPH_DEFS = [
    ("ai",     0xE001, "LABEL_AI",              "ai.general"),
    ("aim",    0xE002, "LABEL_AI MODIFIED",     "ai.modified"),
    ("aig",    0xE003, "LABEL_AI GENERATED",    "ai.generated"),
    # Add more here:
    # ("foo",  0xE004, "LABEL_NEW_NAME",        "new.glyph"),
]
```

### Add New Icon

Add corresponding SVG to `icons/`:

```
icons/LABEL_NEW_NAME_black.svg
```

## SVG Source Convention

- Use **only `*_black.svg`** files — color is applied via `color` property, not SVG fill.
- White fill (`#fff`) and transparent variants are filtered out by the builder.
- SVG viewBox should be square-ish (566x566 for EU icons).

## Testing

Verify built font:

```bash
python3 -c "
from fontTools.ttLib import TTFont
font = TTFont('fonts/ai-labels-font.ttf')
cmap = font.getBestCmap()
for code, name in sorted(cmap.items()):
    print(f'U+{code:04X} → {name}')
"
```

Or open `fonts/ai-labels-font.html` in a browser for visual check.

## Notes

- Font uses Private Use Area (U+E001–U+E003) to avoid conflicts.
- Ligatures are case-insensitive: `AI`, `Ai`, `aim`, `AIM`, `aIg` all map correctly.
- No transparency in TTF — glyphs render in solid `color` value.
